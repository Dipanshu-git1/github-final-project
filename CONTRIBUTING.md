# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Check existing issues to see whether the topic has already been reported.
2. Describe the change or problem clearly, including steps to reproduce bugs where possible.
3. Keep changes focused and update the documentation when needed.
4. Submit your contribution for review and respond constructively to feedback.

Thank you for helping improve this project.
